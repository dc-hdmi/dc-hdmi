교체할 카드를 선택하세요.
선택한 카드보다 더 높은 마나의 카드로 바뀝니다.

게임 설명

① 목표

상대 리더 HP를 25 → 0 만들면 승리.

② 화면 구성

  • 위쪽: 상대 리더 / 상대 필드 / 상대 뒷면 카드(손패 장수)
  • 아래쪽: 내 리더 / 내 필드 / 내 손패

③ 내 턴 자동 효과

턴 시작 시 자동으로:

  • 마나 +1 (최대 7, 매 턴 가득 리필)
  • 카드 1장 뽑기
  • 내 필드 카드 노란 빛 = 공격 가능

④ 카드 소환

손패 카드 클릭 → 필드로 (마나 ≥ 좌상단 코스트)

  • 필드 최대 4자리
  • 소환한 턴에는 공격 불가 (다음 턴부터)

⑤ 공격 방법 (2단계)

  1. 내 필드 카드 클릭 → 선택 (더 밝은 테두리)
  2. 타겟 클릭:
    • 적 카드 → 그 카드와 전투
    • 상단 "상대 리더" 영역 → 리더 직접 공격
  3. 취소: 선택 카드 다시 클릭 또는 하단 "공격 취소"

⑥ 데미지 규칙

  • 카드 vs 카드 = 서로 데미지 (공격자/수비자 모두 다침)
  • 카드 vs 리더 = 공격자 안 다침 (리더 직접 공격은 안전)
  • HP 0 → 카드 파괴

⑦ 속성 상성 (양방향 적용)

  • 삼각: 힘 → 기 → 속 → 힘
  • 양방향: 심 ↔ 지
상황내가 입히는 데미지내가 받는 반격
상성 유리×1.25 (최소 +1)×0.75 (최소 −1)
상성 불리×0.75 (최소 −1)×1.25 (최소 +1)
중립×1.0×1.0

유리 상성 공격은 두 배로 이득 — 더 때리고 덜 맞음.
공격 모드에서 적 카드 위 뱃지로 공격/반격 데미지 미리 확인 가능.

⑨ 턴 종료

  • 아무 때나 "턴 종료" 버튼 (의무 없음, 마나 남겨도 됨)
  • 할 액션 없으면 버튼 금색 깜빡 → 1.5초 뒤 자동 종료

⑩ 배틀 로그

  • 하단 로그 버튼 → 지난 60개 액션 전부 확인
  • 턴 구분선 / 내 액션 / 상대 액션 색상 구분

⑪ 승리 / 패배

  • 상대 리더 HP = 0 → 승리
  • 내 리더 HP = 0 → 패배
  • 상대만 카드 전멸(손패+남은카드+필드=0) → 자동 승리
  • 내 카드 전멸 → 자동 패배
  • 양쪽 모두 카드 소진 → 리더 HP가 많은 쪽 승리, 같으면 무승부

⑫ 연계기 (COMBO)

  • 필드에 같은 속성 3장 또는 같은 타입 3장이 모이면 발동 가능
  • 상대 리더 영역 우측 ⚡ 아이콘이 금색으로 깜빡 → 클릭
  • 여러 연계 성립 시 모달에서 원하는 조합 선택 → 적 전체 −2 데미지
  • 쿨다운 2턴 — 발동 후 2턴 지나야 다시 사용 (뱃지에 남은 쿨 숫자 표시)
  • 연계는 그 턴의 공격을 소모하는 액션 — 발동하면 자동으로 턴이 종료됨
  • 마나 무료, 상대 AI 도 동일 조건으로 연계 사용

⑬ 선공 / 후공 (코인 보정)

  • 매 게임 선·후공은 랜덤 결정
  • 후공자는 첫 턴에 마나 +1 보너스 (코인) — 선공 불리 보상

초보 꿀팁

1. 반격 포함 수치 체크 — 공격 −5 해도 반격 −6 이면 손해
2. 상성 유리할 때 적극 공격 — 양방향 보너스로 거의 무상 트레이드
3. 상대 필드 비면 리더 몰빵 — 리더 공격은 안전
4. 마나는 안 쓰면 사라짐 — 가능하면 쓰기
5. 소환한 카드는 그 턴에 공격 못 함 — 다음 턴에 쓰려면 미리 소환해두기
6. 상대가 사격형 소환하면 전체 −1 — 체력 1인 내 카드들 조심

승리!
